# Foxclaw 配置指南

所有密钥(Key)统一在项目根目录的 `.env` 文件里配置,不写死在代码中。
这样你的 Key 安全(不随代码分发),换 Key 也只改一处。

## 三步开始

1. **复制模板**

   把项目根目录的 `.env.example` 复制一份,改名为 `.env`:
   ```powershell
   # Windows
   Copy-Item .env.example .env
   ```
   ```bash
   # macOS / Linux
   cp .env.example .env
   ```

2. **填入你的 Key**(用文本编辑器打开 `.env`,等号后面填,不要加引号)

3. **启动**
   ```powershell
   foxclaw serve
   ```
   浏览器打开 http://localhost:8000(默认只监听 `127.0.0.1:8000`,`--host` / `--port` 可改)。

   想先确认配置有没有读对:
   ```powershell
   foxclaw config check
   ```

启动时看日志确认:
- `✓ 已加载配置文件 .env` —— .env 被读到了
- `✓ 模型路由: deepseek（deepseek-chat）` —— 模型 Key 生效
- 若显示 `⚠ 模型路由: ... 降级 stub` —— 会注明原因(缺 Key 或缺库)

## 各项 Key 说明

### 大模型(至少配一个,系统才真实工作)

配任意一个,系统自动探测启用。多个都配时按优先级:Claude → GPT → DeepSeek → Gemini → 通义 → 本地。

| 配置项 | 模型 | 获取地址 | 额外依赖 |
|--------|------|----------|----------|
| `DEEPSEEK_API_KEY` | DeepSeek | platform.deepseek.com | `pip install openai` |
| `ANTHROPIC_API_KEY` | Claude | console.anthropic.com | 已内置 |
| `OPENAI_API_KEY` | GPT | platform.openai.com | `pip install openai` |
| `GOOGLE_API_KEY` | Gemini | aistudio.google.com | `pip install -e ".[gemini]"` |
| `DASHSCOPE_API_KEY` | 通义千问 | dashscope.aliyun.com | `pip install openai` |
| `LOCAL_LLM_BASE` | 本地模型 | Ollama/vLLM 的地址 | `pip install openai` |

不配任何模型 Key 也能运行,但 LLM 回复是占位文本(stub),且漂移检测不完整。

### 高德地图(行政 Agent 用,两个 Key 功能不同)

在高德开放平台(lbs.amap.com)控制台创建,**注意要建两个不同类型的 Key**:

| 配置项 | 类型 | 作用 |
|--------|------|------|
| `AMAP_MAPS_API_KEY` | Web服务 | 后端:查真实路线时间、地址转坐标、POI 搜索 |
| `AMAP_JS_KEY` | Web端(JS API) | 前端:画真实地图底图 |
| `AMAP_JS_SCODE` | (安全密钥) | 前端:2021 年后申请的 JSAPI Key 必须配,与上面配对 |

- 只配 `AMAP_MAPS_API_KEY`:路线时间真实,但前端地图是 SVG 示意图
- 只配 `AMAP_JS_KEY` + `AMAP_JS_SCODE`:前端真地图,但路线时间是估算
- 三个都配:行政 Agent 完整(真实路线 + 真地图)
- 都不配:地图降级为 SVG 坐标示意图,路线用直线估算

### 运行参数(可选)

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_MODEL` | 强制指定模型名(如 deepseek-reasoner) | 各 provider 默认 |
| `FOXCLAW_DATA_DIR` | 数据目录 | ./foxclaw_data |
| `FOXCLAW_SHADOW_ROUNDS` | Harness 影子校准轮数 | 20 |

### V2 高级开关(可选,**默认全关**,按需 opt-in)

这些是 V2 架构引入的旋钮,不配则行为与之前一致(安全默认)。

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_MAX_CONCURRENCY` | 微内核调度器并发配额(背压);留空=无上限 | 无上限 |
| `FOXCLAW_PIPELINE_SKILL_DISPATCH` | 允许 Agent 在认知管线内**自主调用工具**(只读自动、有副作用挂起等确认);`=1` 开启 | 关 |
| `FOXCLAW_TRUTH_TO_HKC` | 执行真值经 KDE→KEE **结晶进 HKC**(有 LLM 成本);`=1` 开启 | 关 |
| `FOXCLAW_FINANCE_LLM_ARBITER` | 财务守门人对**模糊金额**叠加 LLM 复核(只 approve→confirm,永不 reject);`=1` 开启 | 关 |

## 安全提示

- `.env` 已加入 `.gitignore`,不会被 git 提交或随代码分发
- 不要把 `.env` 发给别人或上传到公开仓库
- 若 Key 不慎泄露,去对应平台重置(作废旧的,生成新的)

## 常见问题

**Q: 启动显示 stub 降级,但我配了 Key?**
- 检查日志里降级原因。最常见是缺库:DeepSeek/GPT/通义需 `pip install openai`
- 确认 `.env` 在项目根目录(和 `pyproject.toml` 同级),不是在 `foxclaw/` 里
- 确认等号后面没加引号、没多空格

**Q: 地图加载不出来(空白或报错)?**
- 按 F12 看浏览器 Console 报错
- `INVALID_USER_SCODE` → 安全密钥(AMAP_JS_SCODE)没配或配错
- `USERKEY_PLAT_NOMATCH` → JSAPI Key 类型不对(必须是「Web端(JS API)」)

**Q: 端口被占用(10048)?**
- 上一个进程没关。先 `taskkill /F /IM python.exe`(Windows)再启动
