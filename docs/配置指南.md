# Foxclaw 配置指南

所有密钥统一在项目根目录的 `.env` 文件里配置，不写死在代码中。这样密钥不随代码分发，换密钥也只改一处。

## 三步开始

1. **复制模板**

   把项目根目录的 `.env.example` 复制一份，改名为 `.env`：

   ```powershell
   Copy-Item .env.example .env    # Windows
   cp .env.example .env           # macOS / Linux
   ```

2. **填入你的 Key**（用文本编辑器打开 `.env`，等号后面填，不要加引号）

3. **启动**

   ```powershell
   foxclaw serve
   foxclaw config check           # 确认配置读对
   ```

   浏览器打开 http://localhost:8000（默认只监听 `127.0.0.1:8000`，`--host` / `--port` 可改）。

启动时看日志确认：

- `✓ 已加载配置文件 .env` —— `.env` 被读到了
- `✓ 模型路由: deepseek（deepseek-chat）` —— 模型 Key 生效
- 若显示降级提示 —— 会注明原因（缺 Key 或缺库）

## 各项 Key 说明

### 大模型（至少配一个，系统才真实工作）

配任意一个，系统自动探测启用。多个都配时按优先级：Claude → GPT → DeepSeek → Gemini → 通义 → 本地。

| 配置项 | 模型 | 获取地址 | 额外依赖 |
|--------|------|----------|----------|
| `DEEPSEEK_API_KEY` | DeepSeek | platform.deepseek.com | `pip install openai` |
| `ANTHROPIC_API_KEY` | Claude | console.anthropic.com | 已内置 |
| `OPENAI_API_KEY` | GPT | platform.openai.com | `pip install openai` |
| `GOOGLE_API_KEY` | Gemini | aistudio.google.com | `pip install -e ".[gemini]"` |
| `DASHSCOPE_API_KEY` | 通义千问 | dashscope.aliyun.com | `pip install openai` |
| `LOCAL_LLM_BASE` | 本地模型 | Ollama / vLLM 的地址 | `pip install openai` |

不配任何模型 Key 也能运行，但 LLM 回复是占位文本，部分语义能力也会简化。

行程距离按经纬度直线估算，前端绘制坐标示意图，不需要额外地图 Key。

### 运行参数（可选）

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_MODEL` | 强制指定模型名（如 deepseek-reasoner） | 各 provider 默认 |
| `FOXCLAW_DATA_DIR` | 数据目录 | `./foxclaw_data` |

### 执行模式

写操作可以选择在本地执行，或交由受治理的执行服务处理：

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_EXECUTION_BACKEND` | 写操作执行模式：`local` 本地、`serve` 受治理、`auto` 自动选择；只读操作始终在本地 | `local` |
| `FOXCLAW_SERVE_URL` | 治理服务地址 | 空 |
| `FOXCLAW_SERVE_TOKEN` | 访问治理服务的凭证 | 空 |
| `FOXCLAW_SERVE_TOKEN_FILE` | 凭证文件路径，读取时去除首尾空白 | 空 |
| `FOXCLAW_SERVE_HEALTH_INTERVAL` | 健康检查间隔（秒） | `30` |

需要审计的操作不会在本地执行；治理服务不可用时，这类操作不会绕过安全限制。不要把凭证写入代码、日志或共享配置；推荐把 `FOXCLAW_SERVE_TOKEN_FILE` 指向仅服务账户可读的文件。

### 电脑操作范围

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_DESKTOP_ROOTS` | 允许文件与 Shell 操作的工作目录 | 用户主目录 + 系统临时目录 |
| `FOXCLAW_OBSERVE_ALLOW` | 允许屏幕感知（截屏、窗口列表、界面元素树、文字识别） | 关闭 |
| `FOXCLAW_DESKTOP_ACT_DENY` | 默认禁止的高危动作列表 | 删除文件、执行 Shell |

敏感目录与凭据文件始终受保护，不因上述配置放行。每次写操作仍需单独确认，确认一次性有效。

### 安全 / 部署（可选）

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_API_KEY` | 设置后接口需带 `X-API-Key` 头；不设则无鉴权，仅限本机 | 无 |
| `FOXCLAW_CORS_ORIGINS` | 逗号分隔的允许来源，收紧 CORS | `*` |
| `FOXCLAW_BROWSER_HEADLESS` | 浏览器无头模式；`=0` 显示窗口 | `1` |

### 内容闸门

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `FOXCLAW_CONTENT_GUARD_MODE` | `enforce` 拦截 / `audit` 只记录 / `off` 关闭 | `enforce` |
| `FOXCLAW_CONTENT_LEXICON` | 外部词表文件路径，多个用逗号分隔 | 无 |

详见 [CONTENT_GUARD_CN.md](CONTENT_GUARD_CN.md) / [CONTENT_GUARD.md](CONTENT_GUARD.md)。

## 安全提示

- `.env` 已加入 `.gitignore`，不会被 git 提交或随代码分发
- 不要把 `.env` 发给别人或上传到公开仓库
- 若 Key 不慎泄露，去对应平台重置（作废旧的，生成新的）
- 服务默认只监听本机；对外暴露前必须设置访问密钥

## 常见问题

**Q: 启动显示 stub 降级，但我配了 Key？**

- 检查日志里的降级原因。最常见是缺库：DeepSeek / GPT / 通义需 `pip install openai`
- 确认 `.env` 在项目根目录（和 `pyproject.toml` 同级），不是在 `foxclaw/` 里
- 确认等号后面没加引号、没多空格

**Q: 行程地图是空的？**

- 行程点没填经纬度 → 只显示「暂无坐标」提示，填入坐标后自动画示意图
- 经纬度顺序是「经度,纬度」

**Q: 端口被占用（10048）？**

- 上一个进程没关。先结束该进程再启动
