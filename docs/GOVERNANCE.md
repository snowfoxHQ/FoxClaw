# 运行时治理

Foxclaw 面向真实运行中的消息重发、进程中断、长任务与循环场景，提供以下治理能力：

- **消息幂等**：重复送达的消息只处理一次，避免重复执行与重复回复。
- **中断恢复**：识别上次被中断的任务并如实告知，支持从检查点继续。
- **循环防护**：检测反复重试、来回横跳或原地轮询，避免无进展地消耗资源。
- **上下文压缩**：长对话渐进压缩，保留关键标识符与已确认事实。
- **生命周期钩子**：在关键节点可介入处理，并有明确的阻断能力。
- **干预队列**：支持在工作过程中接收用户干预并回收结果。

这些能力默认启用，无需额外配置。配置项见 [配置指南.md](配置指南.md)。
