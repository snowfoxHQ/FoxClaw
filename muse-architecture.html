数据流（“智能体提议 · 守门人许可”）

  1. 1用户下达任务：自然语言描述目标，设备作为瘦客户端仅收发消息。
  2. 2Harness 提议动作：Agent 在隔离单元内规划并生成对外动作，但它只持有占位符令牌。
  3. 3Sentinel 审批：独立的守门智能体逐条判定“许可 / 拒绝 / 转人工确认”，与执行 Agent 系统级分离。
  4. 4凭证注入 + 放行：真实密钥由 Sentinel 在网络边界注入，请求才真正发往外部服务。
  5. 5结果回传 + 审计：完整操作记录留痕；发邮件、支付等不可逆操作回弹给用户确认。
