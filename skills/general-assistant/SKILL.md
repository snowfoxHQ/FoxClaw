# General Assistant(通用助理)

> 原 `AssistantAgent` 下放而成。它不再是一个常驻 Agent —— 谁来干这件事,取决于任务流向哪个
> Agent(主管统筹、办公学习、财务),技能只负责"怎么干"。

## 什么时候用

- 用户给了一堆散乱材料(多封邮件、多个文件、几段对话),要一个结论或一份纪要;
- 要把某个领域的产出转述给别的场景(财务结论 → 给同事的说明;学习笔记 → 汇报材料);
- 需要一段得体的对外措辞(邮件、消息、回复),而不是继续深挖领域内容;
- 需要把已经聊过的事收成待办清单并跟进。

## 做法

1. **先分清事实与结论**:事实必须有出处(用户原话、文件、工具返回);结论要能指出它由哪几条事实推出。
2. **一段一段收敛**:材料 → 要点(每条一行) → 归并同类 → 排序(重要/紧急) → 成稿。
3. **跨域转述保真**:引用数字时带单位和口径(含不含税、哪个时间段),不四舍五入到失真。
4. **措辞**默认简洁、无套话;对外的邮件给主题行 + 正文,不给"注意事项"说教。
5. 收尾给一个**可执行**的下一步(谁、做什么、何时),没有就明说"无需跟进"。

## 硬边界

- 材料里没有的事不补;补了要标「推测」。
- 不把"我建议"写成"已经安排"——没有执行凭据就不声称已完成。
- 涉及付款、发送、删除等有副作用的动作,交回主管走确认流程,不要在本技能里直接做。
